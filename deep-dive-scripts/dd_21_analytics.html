The Analytics Module — Rebuilt From the Ground Up

Rev.io PSA's Analytics module has been completely rebuilt. It is now a full business intelligence platform with a drag-and-drop dashboard builder, a guided chart builder with optional SQL support, custom dataset creation, over 25 visualization types, and Revii Data Analytics for AI-powered natural language queries. Every piece of operational data in PSA — tickets, time, billing, customers, inventory, projects, contracts — is available for analysis.

The module has three main components: Dashboards (visual displays of multiple charts), Charts (individual visualizations built from data), and Datasets (custom data tables you define). SQL Lab is available for advanced users who want direct query access.

→ Connects ToAnalytics draws from every module in the platform. It is the reporting layer for: Service (ticket volume, SLA compliance, tech utilization), Billing (revenue, AR aging, invoice performance), Inventory (stock levels, usage, valuation), Customers (account health, dormancy), Projects (project economics, cost vs. budget), Contracts (utilization, coverage), and Time (billable hours, tech efficiency).
2
Dashboards — Your Business Command Center

Navigate to Analytics > Dashboards. A dashboard is a configurable screen of charts arranged to give you a specific view of your business. You can have multiple dashboards for different audiences and purposes.

Creating a Dashboard

  • Click Add Dashboard
  • Give it a descriptive name
  • Click Edit Dashboard to enter edit mode
  • Use the drag-and-drop builder to add charts as widgets
  • Arrange and resize widgets by dragging
  • Add filters that apply across all charts on the dashboard
  • Save — the dashboard is now accessible to users with report access permissions

Dashboard Filter Controls

Dashboard-level filters let you slice all charts simultaneously. For example: a date range filter that updates all charts on the dashboard to show only the selected period, or a customer filter that narrows everything to one account.

Six Inventory Dashboards (New)

Six pre-built inventory dashboards are available immediately: Inventory Aging, Inventory Valuation, Inventory Levels, Stock Movement & Transaction Reports, Reserved vs. Available Stock, and Pick List Dashboard. These give real-time visibility into inventory health without any setup.

Charts — Building Visualizations

Navigate to Analytics > Charts > Add Chart. Charts are the individual visualizations that populate dashboards.

Chart Types (25+ Available)

The chart builder offers more than 25 visualization types including: Bar Chart, Line Chart, Pie/Donut, Table, Pivot Table, Big Number (KPI display), Scatter Plot, Heat Map, Funnel, Box Plot, Histogram, and more. Choose the type that best communicates the data — bar for comparisons, line for trends over time, table for detailed lists, big number for a single KPI.

Building a Chart — Guided Mode

  • Select your data source (the dataset or built-in table you're querying from)
  • Choose your chart type
  • Configure the query: select metrics (what to measure), dimensions (how to group), and filters (what to include or exclude)
  • Set the time range
  • Preview the result
  • Customize: colors, labels, axis titles, legend
  • Save with a descriptive name

SQL Mode

For advanced users, Charts also supports SQL queries. Write a custom SQL query against the data reference guide's approved tables and visualize the result. SQL mode gives maximum flexibility for complex, multi-table analysis.

💡 Pro TipBuild a library of saved charts you run regularly. A chart saved once can be added to multiple dashboards. Update the chart once and it updates everywhere it appears.
4
Datasets — Custom Data Tables

Navigate to Analytics > Datasets. A Dataset is a custom-defined table of data that you create by selecting fields from approved PSA data tables. Datasets form the foundation of custom charts — instead of defining your data source fresh every time you build a chart, you define it once as a dataset and reference it repeatedly.

The dataset builder includes a built-in data reference guide that shows which tables are available and what fields each contains. You can join tables, apply filters, and define calculated fields within a dataset.

💡 Pro TipThink of a Dataset as a saved, reusable 'view' of your data. If multiple people on your team need charts based on the same underlying data (for example, 'all closed tickets with parts and labor in the last 90 days'), define that once as a Dataset and let everyone build charts from it.
5
SQL Lab — Direct Query Access

Navigate to Analytics > SQL Lab for direct SQL query access to your PSA data. The Query Editor lets you write and execute SQL queries, view results in tabular format, and save queries for reuse.

SQL Lab is intended for users with SQL knowledge who need data that can't be easily built in the guided chart builder. Saved queries are stored in Saved Queries and can be scheduled for regular execution or converted into charts.

⚠ Watch OutSQL Lab queries run against your live PSA database. Poorly written queries (no filters, no limits on large tables) can affect performance. Keep queries focused and always include date range filters on high-volume tables like tickets and time logs.
6
Revii Data Analytics — Natural Language Business Intelligence

Revii Data Analytics is accessed from within the Revii panel: click Ask Revii > Revii Data Analytics. This mode answers business questions in natural language — you type or say what you want to know, and Revii returns a chart, table, or summary drawn from your actual PSA data.

It provides confident, reliable analysis on complex questions, surfaces outliers and trends, and answers questions across customers, invoices, payments, tickets, and quotes without requiring any report-building knowledge.

Sample Queries

  • 'Which technician had the most closed tickets last month?'
  • 'Show me revenue by customer for Q3 2025'
  • 'What is our average ticket resolution time by priority?'
  • 'Which customers haven't had a ticket in the last 90 days?'
  • 'Show me billable vs. non-billable hours by tech this quarter'
  • 'What are our 10 highest-value open invoices?'
💡 Pro TipKeep a running list of the questions you find yourself asking repeatedly. Those are candidates for saved Revii Data Analytics queries or scheduled chart reports.
7
Report Access and Permissions

Access to the Analytics module is controlled by the Report Access permission section in Admin > Roles & Permissions. You can control who can view dashboards and charts, who can build custom charts and datasets, and who has access to SQL Lab.

A common setup: all users can view dashboards, operations managers and billing admins can build charts, and only system admins and senior analysts have SQL Lab access.

8
Scheduled Report Delivery

Charts and dashboards can be scheduled for automatic delivery by email on a recurring schedule. This is how you get data to stakeholders who need it but don't log into PSA regularly — owners, board members, finance teams, or customers.

Configure scheduled reports from the chart or dashboard's settings menu. Set the frequency, delivery time, and recipient email addresses. PSA runs the report and delivers it as a PDF or image attachment.

💡 Pro TipSet up two automatic reports immediately: a weekly AR Aging for your billing team, and a monthly Revenue Summary for your owner or management. These alone eliminate the most common manual reporting requests.

Action Items

  • Build an Operations dashboard and a Finance dashboard as your first two
  • Add the six inventory dashboards if inventory tracking is enabled
  • Build charts for your top 5 KPIs and pin them to your management dashboard
  • Configure scheduled weekly AR Aging delivery to your billing team
  • Configure scheduled monthly Revenue Summary for management
  • Set up Revii Data Analytics and ask it your top 3 business questions
  • Set report access permissions: who can view, who can build, who has SQL access
