1
When to Use Projects vs. Tickets

Most work in Rev.io PSA lives on individual tickets. But when work is complex — when it spans multiple phases, involves several team members, takes weeks or months, and needs to be tracked as a cohesive whole — that's when Projects become the right tool.

A Project is a container that groups related tickets together under a structured hierarchy. All the time, parts, and billing from those tickets roll up to the project level, so you can see progress and cost for the entire engagement without hunting through individual tickets.

❓ PromptDo you manage any multi-phase jobs today — implementations, deployments, large installations, or anything that requires coordinating multiple people over an extended period?
→ Connects ToProjects connect to: Tickets (which are organized into phases inside the project), Customer records (the project is linked to a customer account), Users (assigned as project manager and to individual tickets), Time Logs (hours on project tickets roll up to project-level reporting), and Billing (charges on project tickets flow to the customer's billing account as normal).
2
Project Structure

The hierarchy works like this:

  • Project — the overall engagement. 'Acme Corp Network Upgrade' or 'Smith Residence Security Installation.'
  • Phases — logical stages of the project. Discovery, Design, Implementation, Testing, Handoff. You define these based on how your work flows.
  • Tickets — the individual work orders inside each phase. These are standard PSA tickets with all the same tabs and functionality.
  • Tasks — specific to-do items attached to tickets for granular step tracking.

Progress is tracked at each level. When all tickets in a phase are closed, the phase is complete. When all phases are done, you close the project — archiving the record while keeping the full history accessible.

3
Creating a Project

Go to Projects > Add Project. Key fields: Project Name, Customer, Project Manager, Start and Target Completion Dates, Status, and Description. After saving, click Add Phase, name it, and begin attaching tickets to each phase.

❓ PromptLet's create a project together using a real or upcoming job. What would you call it, and what are the main phases of work?
▲ Platform ImpactWithout Projects, complex multi-phase work gets managed as a loose collection of unrelated tickets. There's no way to see overall progress, no way to compare planned vs. actual hours at the engagement level, and no clear handoff point when the full scope of work is complete.

Action Items

  • Identify 1–2 current or upcoming engagements that would benefit from project tracking
  • Create a project for at least one and build out its phase structure
  • Attach the relevant tickets to each phase
  • Use one project as a template for future similar engagements

Project Management Updates — 2026

The Projects module has been significantly enhanced. Walk through these updates with clients who use projects for managing complex engagements.

Milestones

Projects now support Milestones — point-in-time markers for critical dates and deadlines. Unlike tasks, milestones have no duration or assignees; they simply mark when something must happen: 'Client Approval by March 15,' 'Go-Live Date,' 'Final Delivery.' Milestones are visible on the project detail page, the projects list, and the Gantt chart.

Activity Feed

The Project detail screen now has an Activity Feed that aggregates all project activity into a single chronological timeline — automatically capturing events from tickets, tasks, time entries, purchase orders, and billing as they happen. Filter by event type, date range, or team member to quickly see what's changed since your last visit.

❓ PromptThe Activity Feed is especially useful for project managers who need to brief a stakeholder: 'Here's everything that happened on this project in the last two weeks' — without hunting through individual tickets.

Job Costing Widget

A Job Costing widget on the project's stage side panel gives project managers real-time visibility into project profitability. It aggregates sales vs. costs with a breakdown by materials and labor, updating as ticket line items change. This is the first place to look when a project is approaching its budget limit.

❓ PromptDo you track project budgets today? If yes, the Job Costing widget can surface margin issues in real time — before the project is invoiced — giving you time to have a conversation with the customer if scope is expanding.

Project Duplication

Projects can now be duplicated — copying the project along with its phases, tasks, tickets, and budget hours. When duplicating, you can assign the copy to a different customer. This is the closest thing to a project template currently available: build one project well, then duplicate it for similar engagements and adjust as needed.

Gantt View — Drag and Drop

The Gantt view on the Work tab of the project details screen now supports drag-and-drop adjustments. Drag projects, phases, tasks, and tickets to change timing directly on the chart. Hover for detail, double-click to edit.

Project Filtering

The Projects list can now be filtered by customer and by owner — making it easy to find projects for a specific account or see everything a specific project manager is responsible for, without scrolling through the full list.
